# Sales Data Analysis Project
## Overview
This project analyzes retail sales data using Python, Pandas, and Matplotlib. The goal is to identify sales trends, understand customer behavior, and generate business insights through data analysis and visualization.
## Dataset
The dataset contains retail sales records with information such as:
* Order Date
* Customer Name
* Region
* Category
* Sub-Category
* Product Name
* Sales
## Technologies Used
* Python
* Pandas
* Matplotlib
## Project Objectives
* Calculate total sales
* Analyze sales by region
* Analyze sales by category
* Identify top-selling products
* Identify top customers
* Visualize monthly sales trends
## Project Structure
Sales-Analysis/
├── train.csv
├── sales_analysis.py
├── requirements.txt
├── README.md
└── charts/
## How to Run
1. Install dependencies:
       pip install -r requirements.txt
2. Run the project:
       py -3.13 sales_analysis.py
## Analysis Performed
### Sales by Region
Analyzed total sales across different regions.
### Sales by Category
Compared sales performance among product categories.
### Top Products
Identified products generating the highest revenue.
### Top Customers
Found customers contributing the most sales.
### Monthly Sales Trend
Visualized sales performance over time.
## Results
The project generates charts for:
* Sales by Region
* Sales by Category
* Top Products
* Top Customers
* Monthly Sales Trend
These charts are stored in the `charts` folder.
